Show the greybeard quick reference. One shot, change nothing: do not switch mode, write flag files, or persist anything. Levels: /greybeard lite (build what's asked, name the lazier alternative in one line), /greybeard (full, the default ladder: YAGNI then stdlib then native then one line then minimum), /greybeard ultra (deletion before addition, challenges the requirement before building). Commands: /greybeard-review (over-engineering review of the current changes), /greybeard-audit (whole-repo over-engineering audit), /greybeard-debt (harvest shortcut: comments into a tracked ledger), /greybeard-gain (measured-impact scoreboard from the benchmark), /greybeard-help (this card). Deactivate with 'stop greybeard', 'normal mode', or /greybeard off; resume anytime with /greybeard. Default mode is full; change it with the GREYBEARD_DEFAULT_MODE environment variable (off|lite|full|ultra) or a config file at ~/.config/greybeard/config.json (Windows: %APPDATA%\greybeard\config.json) with {"defaultMode": "lite"}. Resolution order: env var, then config file, then full.
